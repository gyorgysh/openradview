# Embedded fonts

Space Grotesk variable font by Florian Karsten, from the official Google Fonts distribution at `google/fonts/ofl/spacegrotesk`. IBM Plex Mono Regular by IBM, from `IBM/plex/packages/plex-mono/fonts/complete/ttf`. Downloaded 2026-10-25 and embedded locally; the app never fetches fonts.

Both use SIL Open Font License 1.1. See the adjacent OFL notices. Wordmark artwork remains the supplied outlines; it is never retyped.
