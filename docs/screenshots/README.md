# Product screenshot

[viewer.png](viewer.png) is an unchanged native macOS window capture supplied by
the project owner. It shows linked MPR of the included public NLST chest CT in a
pre-release build. The original transparent PNG is 2926 × 2056 pixels; its
SHA-256 is recorded in [sha256.json](sha256.json). No generated anatomy, retouching,
private patient files or agent output is used.

CT data: National Lung Screening Trial Research Team (2013), TCIA,
[NLST](https://doi.org/10.7937/TCIA.HMQ8-J677),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The viewer applies display windowing and spatial resampling. Keep the
[full dataset credits and change notice](../../assets/demos/CREDITS.txt) with reused
images. No endorsement by the dataset contributors, TCIA, IDC or NIH is implied.
The image demonstrates the interface, not diagnostic quality or a disease finding.
